# Matematik Koçum

Modern, premium bir eğitim platformu için Vite tabanlı başlangıç projesi.

## Geliştirme

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Tasarım yönü

- Premium dark SaaS
- Violet/purple accent
- Minimal navigasyon
- Bento grid
- Responsive mobile/tablet/desktop
- Reduced-motion desteği

Geliştirme fazları tamamlandıkça uygulama bu temel üzerine genişletilecektir.
